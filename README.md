# Dragon Shelter – Dragon Energy and Elemental Power Mod

Mod para Dragon Shelter que altera os valores de energia e poder elemental dos dragões.

## Código-fonte

O código-fonte está na pasta `src`.

Projeto:
`DragonShelterDragonNeedsV3.csproj`

## Compilação

Requer .NET SDK compatível com o projeto.

Para compilar em Release, execute:

`dotnet build src\DragonShelterDragonNeedsV3.csproj -c Release`

A DLL compilada será gerada na pasta de saída do projeto.
